# 铃木敏文 · 经营判断与顾客视角

基于《零售的哲学》《零售心理战》两册完整阅读构建的中文 AI 技能，用顾客生活、单品假设、供给条件和一线判断分析经营问题。

包含7个思考模型、10条决策启发式、使用示例、逐章研究笔记与公开来源。由 AI 辅助研究与整理；新的分析不代表铃木敏文本人意见。

## 安装

将本仓库下载到项目的 `.agents/skills/toshifumi-suzuki-perspective/`（Codex），或 `.claude/skills/toshifumi-suzuki-perspective/`（Claude Code）。保留 `SKILL.md` 与 `references/` 的相对结构。

已有同名目录时先备份并比较，不直接覆盖。也可将 [SKILL.md](SKILL.md) 交给支持技能文件的助手，按需加载引用材料。

## 使用

> 用铃木敏文的视角，分析这款商品每天提前售罄，是否应该加订。

> 结合《零售的哲学》和《零售心理战》，检查这个新品方案的顾客价值与供给条件。

明确请求人物视角才激活；普通零售问题不会自动套用。输入具体事实、方案或数据，技能会区分证据、假设与待验证事项，不凭空给出订货数字。
